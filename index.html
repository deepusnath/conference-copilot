How this works

You run a small crew of agents with one human gate: agents discover, vet, draft, and track — you approve and submit. Never let an agent create accounts, pay fees, or press Submit for you; every reputable venue (EDAS, CMT, EasyChair, ConfTool) ties submissions to your identity, and you want eyes on the final package anyway.

Step-by-step setup (Claude Code)

  1. Create the workspace. A folder research-copilot/ containing: profile.md (your research profile — the master context every agent reads), pipeline.json (export it from the Pipeline tab here), and templates/ (master abstract at 150 / 250 / 500 words, extended summary ~1000 words, 100-word bio, IEEE two-column skeleton).
  2. Write profile.md. Fill the profile block inside the master prompt below and save it there. This single file is what makes agent output relevant instead of generic.
  3. Define four subagents in .claude/agents/: scout (discovery), vet (quality + predatory screening), writer (abstract tailoring), registrar (deadline & status tracking). Role prompts are in the master prompt below.
  4. Schedule the weekly sweep. Ask Claude Code to schedule the scout every Monday 08:00 IST producing digest-YYYY-MM-DD.md: new CFPs found, deadlines < 21 days, status changes, and the week's recommended actions.
  5. Keep the human gate. You review the digest, mark Shortlisted here, agents draft; you do the final read and submit yourself.

Vetting checklist (before any submission)

  • Deadline confirmed on the official site, with timezone (EDAS deadlines are Asia/Kolkata unless noted).
  • Proceedings publisher + indexing verified at the publisher, not just claimed in the CFP.
  • Past edition's proceedings actually findable (IEEE Xplore, Scopus, ACM DL).
  • Organizing committee are real, findable academics; venue passes the Think-Check-Attend test.
  • Fee is in the normal range (IEEE regional conferences typically $300–600; be suspicious of pay-more-publish-faster tiers).
  • Camera-ready + author-registration deadlines noted the moment you're accepted.
